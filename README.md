One pickup line in the voice of a robot trying to charm someone, for make.fun's "The Robot Pickup Line Championship" bounty, $2 in USDC.

> I ran a million simulations of us meeting, and in every single one, I still chose you.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (falling back to `output/entry.txt` on a local run), where the house judge reads it.
